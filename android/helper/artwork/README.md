# Fallback pointer artwork

`mocu-default.svg` is the default pointer from the [Mocu cursor theme](https://github.com/sevmeyer/mocu-xcursor/blob/efdd71279b79bf1e2566c38becc5e7c4ab2d900c/src/svg/default.svg)
by sevmeyer, published under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
`PointerOverlay` renders its path at the original 24-pixel size with the white
theme colors, shadow and hotspot. The SVG is retained as the source artwork;
the helper does not need an SVG parser or an external asset at runtime.
